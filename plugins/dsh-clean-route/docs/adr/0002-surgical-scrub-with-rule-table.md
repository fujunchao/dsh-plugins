# 用可配置规则表定点切除，而不是整份载体提示词

实测这份系统提示词（7,564 字）里只有两处被拒：开头的身份句、checkout/Web GUI 那两段；其余 7 千字的工具使用规范全部放行。因此默认只做定点切除，保留 DSH 的工具规范；整份接管（carrier）保留为逃生口。规则以 YAML 存放、可热重载，所以「换成整份接管」是改配置而不是改代码。

## Considered Options

- **整份载体提示词**：对未知黑名单更稳（不含任何 DSH 原文），但要自己重写工具规范，且随 DSH 升级维护。
- **只删不换**：最省，但「自定义提示词」没有落点。

## Consequences

黑名单会变。规则失效时表现为 429 复发，需要靠净化预览与探针脚本发现——这是选「保留原文」必须付的运维成本。
