# dsh-workspace-recent

侧边栏的项目（工作区）按"最近工作"自动排序。这个文件只收录本项目的术语，不放实现细节。

## Language

**工作区（Workspace）**：
侧边栏里的一个项目分组条目：一个目录、一个标题，以及归属它的会话。用户口中的「项目」就是它。
_Avoid_: 项目（代码与文档里一律用工作区）、folder、repo

**持久顺序（Durable Order）**：
宿主 registry 里工作区 id 的先后。侧边栏、新建会话的工作区下拉、下次启动都只认这份顺序。
_Avoid_: 显示顺序、排序结果

**最近工作（Recent Work）**：
一个工作区内参与计算的会话里最大的会话时间。会话时间是「创建时间」与「最后一次用户消息时间」两者取大。
_Avoid_: 最后修改、last activity

**会话活动（Session Activity）**：
用户亲手发出一条消息这一事实。助手回复、工具调用、子代理跑完都不是。
_Avoid_: 活动、事件、流量

**空白会话（Blank Session）**：
已创建、尚无用户消息的会话。它参与「最近工作」计算，代表「刚在这个工作区开了张」。

**子代理会话（Subagent Session）**：
由助手派生的子会话。它代表助手在工作，不代表用户在工作，不参与计算。

**归档会话（Archived Session）**：
用户判定已收尾、放入归档集合的会话。不参与计算，但它的位置槽仍然保留，取消归档会回到原处。
_Avoid_: 删除（归档不是删除）

**自动模式 / 手动模式（recent / manual）**：
自动模式按最近工作排序；手动模式下插件完全不碰顺序，手动拖拽是唯一真相。
