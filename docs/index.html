DSH 插件集 · 市场索引

这个站点只做一件事：给 DeepSeekRuntime（DSH）的「发现」页提供一个插件索引。

在 DSH 里添加索引源

  1. 打开 插件 → 实验性插件 → 打开 自定义插件索引。
  2. 切到 发现 → 添加索引源，填入下面的地址。
  3. 搜索插件名 → 打开卡片 → 安装。
https://fujunchao.github.io/dsh-plugins/index.json

原始文件

索引 JSON：index.json
插件源码与发版流程：github.com/fujunchao/dsh-plugins

索引由仓库 CI 生成，每个版本固定在某个提交上；DSH 只校验格式，不校验声明。
